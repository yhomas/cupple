
# OpenHands 開発開始指示プロンプト

Hi OpenHands,
I want to build a Flutter-based custom SNS app for married couples/partners called "ありがとうアプリ" (Thank-you App).
It needs to be fully responsive for both Mobile (iOS/Android) and Web, using Firebase as its backend.

I have already created the Requirements Definition (PRD) and Technical Design Document in this directory. Please read them carefully first:
 * requirements_definition.md (要件定義書)
 * technical_design.md (技術設計書)

Your first task is to set up the **Phase 1: Project Setup & Foundation**.

Please perform the following steps carefully:

 1. **Initialize the Flutter Project:**
   Create a new Flutter project in the current directory if it is not initialized yet.
   Please make sure to support iOS, Android, and Web platforms.

 2. **Setup Dependency Configuration (pubspec.yaml):**
   Add the following essential packages to pubspec.yaml using stable versions:
   * State Management: flutter_riverpod, riverpod_annotation
   * Database / Auth: firebase_core, firebase_auth, cloud_firestore
   * Navigation: go_router (optional, or state basic routing if simpler)
   * UI / Icons: google_fonts, lucide_icons (or similar standard icons)
   * Dev Dependencies: build_runner, riverpod_generator

 3. **Create the Project Directory Structure:**
   Create the "Feature-First" directory structure inside the lib/ directory as specified in Section 2 of technical_design.md.
   * lib/core/ (theme, router, widgets)
   * lib/features/auth/ (data, domain, presentation)
   * lib/features/couple/ (data, domain, presentation)
   * lib/features/cards/ (data, domain, presentation)
   * lib/features/report/ (data, domain, presentation)

 4. **Prepare basic Core Files:**
   * Create lib/core/widgets/max_width_container.dart with the MaxWidthContainer implementation defined in Section 5.1 of technical_design.md.
   * Setup a basic Material 3 color theme config in lib/core/theme/ (using a warm palette: pastel pink, warm orange, ivory tones).

⚠️ **CRITICAL INSTRUCTIONS FOR THIS STEP:**
 * Please **DO NOT** write complex Firebase logic or UI screens yet. Just focus on initializing the project, installing dependencies, creating the folders, and setting up the basic responsive container and theme.
 * After completing these steps, please show me the updated folder tree and explain what files you have generated.

Let's start!
